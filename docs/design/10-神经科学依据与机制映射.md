# 器灵 / Artifact Spirit — 神经科学依据与机制映射

> 文档编号：**DES-RES-003**
> 日期：2026-09-15
> 触发：**P1（分级记忆）的动因需要被讲清楚**——它是**为优化 LLM 注意力而做的设计**，"注意力是有限资源"这一约束借自脑科学研究（人类同样有注意力消耗问题）；同时需要把整套记忆机制的科学依据补全，并逐条落到 Agent 侧的可测判据。
> 结论摘要：**真正稀缺的是注意力，不是存储。** 脑科学在本项目里提供两样东西——**约束**（同时在线的信息量有上限）与**量**（容量 4±1、重要性与频率独立、衰减长尾形状、共现统计结构）。它**不提供正确性**：每条机制都必须由 Agent 侧指标裁决（[DES-RES-002 §5](./09-机制决策依据研究.md) 三关准入）。

## 1. 结论先行（三条）

1. **分级抽象的动因是注意力预算，不是存储容量。** 存储对 Agent 近乎免费，上下文与注意力才是稀缺的（DES-RES-002 §2）。脑科学提供的约束是"**同时在线的信息量有上限**"，因此第一手段是**抽象与压缩**，而不是删除。
2. **约束不同 → 机制不能照搬。** 人脑的遗忘有被动成因（容量 / 代谢 / 干扰），Agent 没有；**Agent 的"遗忘"必须落在注意力侧**（排序、分级、降级），物理删除只做治理（D-16 / D-17 / D-23）。
3. **脑科学给的是"量"。** 4±1 的容量、重要性与频率的独立性、衰减的长尾形状、共现的统计结构——每一个都能翻译成一条 Agent 侧判据与一条放弃条件（§3 / §6）；**翻译不了的**（RIF、模式分离、交错重放、元记忆）一律进实验特性（D-19）。

## 2. 机制一：注意力预算 → 分级抽象（P1 的依据）

> 本节即 [DES-000 §1.1](./00-方案设计.md)「P1 的来源」所引用的 **§2.1**。

### 2.1 为什么是"分级抽象"

**稀缺的是注意力，不是存储。** 生物侧对比见 [DES-RES-002 §2](./09-机制决策依据研究.md)，此处只列注意力侧：

| 资源 | 生物大脑 | LLM Agent | 设计含义 |
|---|---|---|---|
| 存储 | 有限、有代谢成本 | **近乎免费** | **不以"省存储"为理由删数据** |
| **同时在线的信息量** | 工作记忆容量有上限（A/B 级） | 上下文窗口有限，且**长度上升后单位信息利用率下降**（A 级） | **分级抽象是第一手段** |
| 注意力成本 | 注意资源有限、需要分配（A 级） | 每个 token 都要付费，且与推理能力互为代价（B 级） | 注入的记忆必须**预算化**，而不是"尽量多" |

**`L0/L1/L2` 就是对"同时在线信息量上限"的工程化回答**：

```
L0 模糊印象（~50 token/条）  → 覆盖最广、成本最低：作用是"筛掉不相关"
L1 主题概览（~2k token）     → 已足够判断"有没有用"：决定要不要深入
L2 细节（按需展开）          → 只在确认需要时展开：精确但贵
```

其信息结构是 **L2 ⊃ L1 ⊃ L0**（层间包含，见 [TERM-000 §7](./06-术语与命名规范.md)），所以逐级展开**永远不丢信息**，只是推迟成本——这正是它优于"按频率删记忆"的地方：**注意力层面的"遗忘"可逆**（DES-RES-002 §3.1）。

### 2.2 脑科学侧的依据（只列可检验的结论）

| # | 结论 | 强度 | 对本设计的直接含义 |
|---|---|---|---|
| 1 | 选择性注意存在**瓶颈**：无关信息在加工早期即被过滤（Broadbent 1958；Cherry 1953） | A | **注入前先过滤**（M1 显著性、L0 粗筛），而不是"先全塞进去让它自己忽略" |
| 2 | 注意是一种**有限且可分配**的资源（Kahneman 1973；Lavie 2005 负荷理论） | A | 注入的记忆量与推理能力**互为代价** → 必须设预算上限 |
| 3 | 工作记忆容量约 **4±1 组块**（Cowan 2001；Miller 1956 的 7±2 在排除复述/组块策略后收敛到约 4） | B | 工作记忆组块上限、每轮注入条数（M6、M9） |
| 4 | 容量限制的是**组块数**而非信息量：组块化 / 压缩可显著提升有效容量（Chase & Simon 1973） | B | **压缩（摘要）比塞入更多条目更有效** → L0/L1 的价值所在 |
| 5 | 认知负荷会挤占推理资源（Sweller 1988） | B | 上下文中每多一条无关记忆都在扣分（对应 G4） |

> 第 4 条尤其关键：它同时解释了"**为什么分级不是删减信息**"——抽象提高的是**有效容量**。

### 2.3 工程侧的依据（同一方向的独立证据）

| 结论 | 强度 |
|---|---|
| 长上下文中，位于**中间位置**的信息利用率显著低于首尾（Liu et al. 2023 / TACL 2024，"Lost in the Middle"） | A |
| 上下文长度增长时，单位 token 的边际收益递减、成本线性上升 | A |

> 两条指向同一件事：**注入要少而准**，且**位置也影响可用性**——这正是"L0 摘要要短、候选集要小"的工程理由。

### 2.4 设计落点

| 落点 | 位置 |
|---|---|
| 三级定义与逐级展开 | [LLD-AL2 §5 M9](./layers/AL2-核心层详细设计.md) |
| L1 是缓存非真相源、**不得在热路径生成**（`prefetch` 300ms 护栏） | 同上（INV-1） |
| 预算内裁剪顺序：L2 → L1 → L0 | 同上 |
| 工作记忆 5 组块上限 | [LLD-AL2 §5 M6](./layers/AL2-核心层详细设计.md) |
| 目标与不变量 | [DES-000 §1.1 P1 / §1.4 V1](./00-方案设计.md)、[DES-CHARTER §3 G4](./08-设计纲领.md) |

### 2.5 Agent 侧判据（这一条必须可量）

| 指标 | 定义 | 方向 |
|---|---|---|
| **注入预算遵守率** | 记忆侧注入 token / 该轮预算 | 100%（硬约束，不是"尽量"） |
| **注意力效率** | 被真正引用的记忆条数 / 注入的条数 | ↑（分级加载的核心收益） |
| **召回命中率** | 需要的记忆出现在候选集里的比例 | ↑（分级不能牺牲它） |
| **token 效率** | 达到同等召回质量所需注入 token | ↓ |

> **放弃条件（可证伪）**：若"逐级展开"的注意力效率不低于"全量注入 L2"，而召回命中率反而更低，则 M9 退化为 L0/L2 两级。

## 3. 逐条机制映射（总表）

| 机制 | 脑科学侧依据（强度） | Agent 侧判据 | 放弃条件 |
|---|---|---|---|
| **M9 分级加载** | 注意瓶颈（A）+ 组块化提升有效容量（B）+ 长上下文中间遗忘（A） | 注意力效率 ↑、注入预算遵守率 100%、命中率不降 | §2.5 |
| **M1 显著性过滤** | 情绪唤醒 / 自我相关调节编码强度（McGaugh 2004、Rogers et al. 1977，B） | 重要记忆的漏记率、噪声落盘率 | 漏记率不优于"全量写入" |
| **M2 巩固升格** | 系统巩固：情景 → 语义、去情境化（Squire & Alvarez 1995、Winocur et al. 2010，B） | 跨会话复现主题的召回质量 | 升格后召回质量无提升 |
| **M3 衰减排序** | 遗忘曲线长尾形状（Ebbinghaus 1885 + Wixted & Ebbesen 1991，A）；检索练习增强保持（Cepeda et al. 2006、Roediger & Karpicke 2006，A） | 排序区分度（NDCG / MRR）、**低频关键记忆**的召回率 | 长尾形状不优于单一指数 |
| **M4 扩散激活** | 语义启动与扩散激活（Collins & Loftus 1975、Meyer & Schvaneveldt 1971，A）；共激活强化联结（Hebb 1949、Bliss & Lømo 1973，B） | 关联召回的额外命中率、误召回率 | 关联召回不带来净增益 |
| **M5 多因子融合** | 编码特异性 / 线索依赖回忆（Tulving & Thomson 1973、Godden & Baddeley 1975，A）；**重要性与频率是两个独立维度**（A） | 召回质量（D-13 门槛）、"低频但关键"命中率 | 融合不优于任一单因子 |
| **M6 工作记忆 4±1** | 工作记忆容量约 4 组块（Cowan 2001，B） | 会话内话题切换后的指代 / 意图保持率 | 5 组块与更小容量无差异 |
| **M11 元认知 / 可审查** | 元认知监控"知道自己不知道"（Nelson & Narens 1990、Hart 1965，C） | 低置信 / 空召回时是否**显式告知** | 见 §6.4 S-4 |
| **实验特性**：RIF / 模式分离 / 交错重放 / 元记忆 | 生物侧成立、**Agent 侧收益未证**（C） | — | 默认关闭（D-19） |

> **读法**：左列**不是理由，是假设来源**；右列才是判据。任何机制只要右侧判据不达标，就走 DES-RES-002 §5.1 的第二关——降级为实验特性。

## 4. 逐机制：这些"量"是怎么落到参数上的

### 4.1 M1 显著性：为什么"重要性"必须独立于"频率"

情绪唤醒与自我相关会**加强**编码（McGaugh 2004；自我参照效应，Rogers et al. 1977，B）——也就是说，**重要性是编码期就打上的标记**，而不是访问次数累积出来的结果。

- 落点：M1 的五项启发式（新颖度 / 显式指令 / 实体密度 / 情绪强度 / 核心一致性偏移）；M5 中 `importance` 与 `recency` **解耦**（D-20）。
- 反面教训：按访问频率衰减会系统性淘汰"低频但关键"的记忆（DES-RES-002 §4.1）——**这不是"不够像脑"，而是与可检验结论相悖。**

### 4.2 M2 巩固：为什么是"单向递进 + 离线执行"

情景记忆随时间推移摆脱情境依赖、转为语义知识（系统巩固，B）；重放多发生在离线阶段（Wilson & McNaughton 1994，C）。

- 落点：单向迁移（工作 → 情景 → 语义 → 程序）、**后台维护任务执行**、`derived_from` 保留来源链（M2）。
- **本文不支持的**：把"交错重放"作为默认行为——列 D-19 实验特性。

### 4.3 M3 衰减：为什么是"长尾"而不是"指数清零"

纯指数衰减与数据拟合长期偏差，幂律 / 混合模型能更好地描述"近期下降快、远期长尾"（Wixted & Ebbesen 1991，A）。

- 落点：`strength(t)` 取混合形状（指数 + 幂律），**仅作排序信号**（D-16）；访问回升对应间隔重复 / 检索练习（A）。
- 判据：在"近期 + 远期混合"的评测集上，混合形状的排序质量（NDCG）应优于单一指数。

### 4.4 M4 扩散激活：持久联结与瞬时激活必须分开

扩散激活是**瞬时**的检索促进（A），而共现统计是**持久**的结构（B）。

- 落点：`relations` 边（持久，随共现累积）与单轮扩散值（瞬时，不入库）分属不同字段，**不得混用**。
- 判据：扩散带来的额外命中率必须大于它带来的误召回代价。

### 4.5 M5 多因子融合：为什么需要"多路"

回忆依赖**线索**：线索与记忆在编码期的匹配程度决定能否想起（编码特异性，A）。不同线索（语义 / 实体 / 时间 / 关联 / 重要度 / 核心一致性）命中的是**不同的记忆子集**。

- 落点：六因子加权融合（含 D-10 实体因子）；`Scored.raw` 必须保留，以便回答"这条为什么被召回"。
- 判据：见 §6.1。

### 4.6 M6 工作记忆：4±1 限制的是"组块数"而非"信息量"

容量限制作用于组块（B）→ 上限取 **5**（4±1 上界）；同话题按 `chunk_key` 归并、累积激活；被淘汰的组块随会话结束固化进情景记忆，**不丢数据**。

- 判据：话题切换后的指代 / 意图保持率。

### 4.7 M9 分级加载

见 §2（这是本文的核心机制）。

### 4.8 M11 元认知：可审查是产品需求，脑科学只贡献"知道自己不知道"

可读 / 可审 / 可干预（P2）**不需要脑科学背书**——它是产品需求（DES-RES-002 §6.2）。脑科学在这里只有一个可用假设：**元认知监控**（C 级）→ 系统应能对"我可能不知道"给出**显式信号**。

- 落点：`review` / `trace` / `correct`（M11）；低置信与空召回的显式提示（S-4，待实测）。

## 5. 不可照搬的三条边界

| # | 边界 | 后果 |
|---|---|---|
| 1 | **存储约束不成立**：人脑因容量 / 代谢必须删，Agent 不必须 | 禁止"因容量而删"；删除只做治理（D-17） |
| 2 | **生物遗忘有被动成因，Agent 没有**——不删就永远在 | Agent 的"遗忘"必须主动设计为**排序 + 分级 + 降级**（D-16 / D-23） |
| 3 | **目标函数不同**（生存适应 vs 任务表现） | 一切判据只能是 **Agent 能力指标**（召回质量 / 任务成功率 / token 效率） |

> 这三条是 DES-RES-002 §1 / §2 的直接延续：**"人脑如此"既不能立项，也不能否决。**

## 6. Agent 侧可测判据（G6 的落地）

### 6.1 度量三件套（只认这三类）

| 类 | 指标 | 说明 |
|---|---|---|
| **召回质量** | LoCoMo / LongMemEval / 自建集上的命中率、MRR、NDCG | 门槛见 D-13（LoCoMo ≥70、LongMemEval ≥75） |
| **注意力效率** | 注入信噪比 = 被引用条数 / 注入条数；注入 token 利用率 | **本文新增的判据重点**（对应 G4） |
| **成本** | 每轮记忆侧 token、每次召回延迟（`prefetch` 300ms 护栏） | 不允许"用质量换成本"而不留证据 |

### 6.2 分级加载的对照实验

| 组 | 注入方式 |
|---|---|
| A（基线） | 全量 L2 注入（Top-K 原文） |
| B | 仅 L0 |
| C（器灵） | L0 粗筛 → L1 判断 → 按需 L2 |

假设与放弃条件见 §2.5。评判时**质量与注意力效率必须同时看**，不允许只看质量。

### 6.3 每条机制都要有可证伪表述

§3 总表右列即各组机制的放弃条件；实现时须把这些条件落成测试或评测项，**否则不算通过第二关**。

### 6.4 证据驱动的完善建议（待实测，默认不进主线）

整理本文证据时发现 **5 处机制缺口**。它们都是"合理性成立、有效性待测"，按 D-18 走实验开关，**不影响 P 档任何承诺**：

| # | 建议 | 依据 | 判据（怎么算通过） |
|---|---|---|---|
| **S-1** | **区分"被召回"与"被采用"**：`recency` 回升只对被任务**实际使用**的记忆加权，而不是"出现在候选集里"就加分 | 检索练习 / 测试效应（A）：增强来自**成功提取**而非重复接触 | 关键记忆留存率上升，且排序质量不降 |
| **S-2** | **持久联结与瞬时激活分字段**（§4.4） | 扩散激活是瞬时的（A） | 误召回率下降、关联命中率不降 |
| **S-3** | **概览稳定性**：给 L1 概览加"最短稳定期"，避免频繁重算导致**线索漂移**（与 M10 冲突时按 D-14 保 M9） | 线索稳定性影响可检索性（编码特异性，A） | 概览重算次数下降且召回质量不降 |
| **S-4** | **显式表达"不知道"**：低置信 / 空召回时向宿主返回显式提示，而非静默返回空结果 | 元认知监控（C） | 用户可感知的"该想起却没想起"事件减少 |
| **S-5** | **注入位置**：记忆块置于上下文**首尾**优于中间（当前已由"L0 短摘要 + 小候选集"部分缓解） | 中间遗忘（A） | 同 token 预算下注意力效率上升 |

> 五条都**必须先有实测数据**（P4 第二关）。其中 S-1 / S-2 与现有字段结构直接相关，建议在 M3+ 的实现任务里一并评估。

## 9. 一句话总结

> **器灵的记忆分级不是"因为人脑这样"，而是因为注意力才是稀缺资源。** 脑科学把这件事量得比我们准（4±1 的容量、重要性与频率独立、长尾衰减、共现结构），所以它值得被借鉴；至于借鉴过来有没有用，**只能由 Agent 在真实任务上的表现来裁决**（P4 第二关）。
